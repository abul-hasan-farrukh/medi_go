# MediGo - A Pathology Portal

A modern healthcare and digital pathology service portal built using **React.js** and **Vite**. MediGo aims to provide an intuitive platform for managing pathology-related services through dedicated interfaces for users, workers, and administrators.

This repository currently contains the frontend implementation of the project.

---

##  Features

### 👤 User Module

* User Registration
* User Login
* Responsive User Interface
* Service Navigation
* Form Validation

### 👨‍⚕️ Worker Module

* Dedicated Worker Dashboard
* Service Management Interface
* Workflow-Oriented Components

### 🛠️ Admin Module

* Administrative Interface
* Management Components
* System Monitoring Features

###  General Features

* React Component-Based Architecture
* Client-Side Routing
* Modular Folder Structure
* Reusable Components
* Responsive Design
* Custom Validation Logic
* Clean and Scalable Codebase

### Clone the Repository

##  Architecture Overview

The application follows a modular component architecture:

* **Admin Module** – Administrative functionalities and management screens.
* **User Module** – User-facing pages and workflows.
* **Worker Module** – Operational interfaces for service personnel.
* **Common Module** – Shared and reusable components.
* **PathMapper** – Centralized route management.
* **Validation Layer** – Form validation and input verification.
